# Atividade de Vetores - Java

Lista de 20 exercicios sobre vetores e lacos de repeticao em Java.

## Como executar

Compilar e rodar um exercicio (exemplo com o 01):

```
javac Exercicio01.java
java Exercicio01
```

Obs.: ao digitar numeros decimais, use virgula ou ponto conforme a configuracao do seu computador (no Brasil, normalmente virgula).
